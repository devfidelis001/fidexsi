Installation

Installation Steps

  1. Download the installer. Click Download above to get FIDEX-SI-Setup.exe.
  2. Open the installer. Double-click FIDEX-SI-Setup.exe in your Downloads folder. If Windows SmartScreen appears, click More info, then Run anyway.
  3. Follow the prompts. Choose where to install (the default is fine) and click Install. Desktop and Start Menu shortcuts are created for you.
  4. Launch FIDEX SI. Double-click the FIDEX SI icon on your Desktop, or open it from the Start Menu.
  5. Install the AI model (if required). If FIDEX SI says the AI model is missing, use Download AI model above. Keep both parts (.zip.001 and .zip.002) together in your Downloads folder, then restart FIDEX SI. It joins and installs the model automatically.

About FIDEX SI

A personal agent, not only a chatbot.

FIDEX SI is more than an AI chatbot. It is a personal AI assistant designed to help you think, learn, build, manage projects, and get things done.

Built to connect artificial intelligence with real computer work, it helps you move beyond asking questions to taking meaningful action.

What FIDEX SI Can Do

  • Conversations: answers questions, explains concepts, writes content, solves problems and helps with everyday tasks.
  • Take Over Mode: give it a goal or project. It plans, carries out supported actions, tracks progress, handles setbacks, continues unfinished work and asks for approval when needed.
  • Guide Mode: step-by-step help to learn skills, troubleshoot problems and work through projects while you stay in control.
  • Computer Interaction: supported mouse, keyboard, application, folder and file actions.
  • Live Vision (Eye): understands your screen, watches for changes and checks that tasks are on track.
  • Research: gathers and organizes information on business ideas, jobs, technology and more.
  • Project Memory: keeps decisions, tasks and progress so you can continue across sessions.
  • Image and File Assistance: works with supported images and files.

Two Ways to Work

Guide Mode: learn and work with AI. It explains, advises and teaches while you stay involved.

Take Over Mode: give AI the task. Describe the goal and FIDEX SI plans, executes supported steps, tracks progress and asks for your input when needed.

Our Vision

FIDEX SI is being built to become a dependable personal agent that understands your objectives, manages projects, uses your computer and turns ideas into real results. It is built around user control and the belief that AI should not only tell you what to do but help you do it.
